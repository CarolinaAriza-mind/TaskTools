# AI Usage Disclosure

This project was developed with AI-assisted workflows using **ChatGPT** as a development support tool.

AI assistance was used to accelerate implementation, debugging, refactoring, documentation, and architectural decision-making throughout the project lifecycle.

---

## How AI Was Used

### Architecture & Planning

- Define project structure
- Design backend/frontend separation
- Model recursive task relationships
- Organize Docker-based infrastructure
- Propose scalable folder organization

### Backend Development (NestJS)

- CRUD endpoint scaffolding
- Recursive task tree implementation
- Recursive metrics calculation logic
- TypeORM entity relationships
- DTO validation patterns
- Error handling improvements
- Pagination implementation
- Docker and PostgreSQL configuration debugging

**Examples:**

- Recursive subtasks with self-referencing entities
- Recursive workload metric calculations
- Query parameter pagination support

### Frontend Development (Next.js)

- Component structuring
- Recursive task rendering
- Responsive UI improvements
- Pagination UI logic
- Axios service layer setup
- State management fixes
- React hooks debugging
- Mobile-first responsive adaptations

**Examples:**

- Recursive `TaskTree` rendering
- Paginated kanban columns
- Responsive layouts for desktop/mobile
- Fixing React rendering and state update issues

### DevOps & Docker

- Dockerfile setup
- Docker Compose orchestration
- PostgreSQL environment configuration
- Container networking troubleshooting
- Build/debug workflows

**Examples:**

- Fixing missing environment variables
- Solving container startup race conditions
- Debugging API connectivity between containers

### Documentation

- Generate and refine the README
- Improve technical documentation clarity
- Organize API documentation
- Create setup instructions
- Write feature descriptions

## Development Responsibility

All architectural decisions, validations, testing, and final implementation choices were reviewed and validated manually during development.

AI was used as a productivity and support tool, not as an autonomous system.

## Purpose

The use of AI in this project aimed to:

- Accelerate development
- Improve debugging workflows
- Reduce repetitive boilerplate work
- Enhance documentation quality
- Explore alternative implementations faster

AI-assisted development was treated as a **collaborative engineering workflow** rather than automatic code generation.
